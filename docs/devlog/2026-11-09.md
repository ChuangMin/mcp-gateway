## 關鍵決定（細節看 #1 和 ADR）

- 開源（Apache-2.0）、自架；一間公司部署一套，只對接一個 Entra Tenant
- Workspace 是公司內的團隊或部門；一個 User 可以屬於多個 Workspace
- 只聚合 tools；tool 名稱一律是 `前綴__tool名`，可以設別名
- 用 Role 控管，可以細到每個 tool；萬用字元只涵蓋已核准的 tool
- 登入：MCP OAuth（轉去 Entra 登入）和 API Token，兩種第一版都做
- 技術：TypeScript、Hono、MCP SDK、Drizzle、PostgreSQL、React 加 Vite、Docker compose
- 測試只從 Gateway 對外的 HTTP 介面切入；PostgreSQL 用真的，Upstream Server 和 Entra 用假的，時鐘可以注入
